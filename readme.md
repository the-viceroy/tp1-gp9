**Enseignante :** Fatma Ellouze  

## Objectif

Ce TP a pour objectif de se familiariser avec les bases du langage HTML. Il permet d’apprendre à créer une page web, à utiliser différentes balises HTML, à insérer des images et à créer des liens hypertextes entre plusieurs pages.

## Travail réalisé

Le projet consiste à créer un site web consacré à plusieurs applications mobiles :

- TikTok ;
- Instagram ;
- Facebook ;
- WhatsApp ;
- ChatGPT.

La page principale du site est le fichier `index.html`. Elle contient les logos des applications, chaque logo étant associé à un lien hypertexte vers une page détaillée.

Chaque page détaillée contient :

- le nom de l’application sous forme de titre ;
- un paragraphe présentant son utilité ;
- une image permettant de revenir à la page d’accueil.
